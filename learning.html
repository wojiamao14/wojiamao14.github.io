数学 · 线性代数 · 示例 矩阵与线性变换 从几何视角理解矩阵的本质

矩阵的每一列描述一个基向量变换后的去向。例如，把平面上的两个基向量分别拉伸到原长的两倍和三倍，单位正方形就会变成宽为 2、高为 3 的矩形。

计算机 · C++ · 示例 C++ 基础知识整理 变量、函数与基础语法

用 int 声明整数变量。把重复计算写成函数，例如 int square(int x) { return x * x; }，调用 square(3) 会得到 9。

人工智能 · 深度学习 · 示例 从神经网络到 Transformer 建立对现代人工智能的初步认识

神经网络通过多层变换提取特征。Transformer 使用自注意力，让每个词元根据上下文汇集其他词元的信息，例如借助句中其他词判断一个多义词的含义。

数学 · 高等数学 · 示例 导数与微分的理解 从变化率到局部线性近似

导数描述函数的瞬时变化率。以 f(x) = x² 为例，在 x = 2 附近，输入变化 Δx 带来的输出变化约为 4Δx，误差是 (Δx)²。

工程 · 工程实践 · 示例 工程问题与数学建模 如何将现实问题转化为数学问题

以教室照明为例，可把灯具数量和布局作为变量，把最低照度作为约束，以降低耗电为目标，再用实际测量检查模型假设。
